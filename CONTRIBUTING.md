# Contributing to Amun

Thank you for your interest in helping improve Amun!

Amun is an educational Python robot simulator created to help people learn programming.

## How to Contribute

You can help improve Amun by:

- Reporting bugs and unexpected behavior.
- Suggesting new features or educational improvements.
- Improving documentation and examples.
- Submitting code changes through pull requests.

## Before Submitting Changes

1. Open an issue to discuss significant changes before starting work.
2. Explain the purpose of your changes clearly.
3. Include steps to reproduce any reported bugs.
4. Test your changes and document any known limitations.
5. Keep pull requests focused on one improvement whenever possible.

## Pull Requests

When submitting a pull request:

- Describe what you changed and why.
- Explain how you tested your changes.
- Update the documentation if necessary.
- Be respectful and constructive when discussing feedback.

Thank you for helping make Amun better for learners and educators!
